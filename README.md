# Investigating primary productivity in a freshwater estuary

<p> <strong>R:</strong> Written to calculate Net Productivity (NP), Respiration (R) and Gross Productivity (GP) from photosynthesizers in Old Woman Creek using data collected from paired light/dark bottle experiments (Bottle Data) and time-series data collected from sondes (Historical Data). </p>

<p> <strong>Python:</strong> Data visualization using bar graphs, line graphs, multiple subplots, and plot annotations.</p>

<p> <strong>Historical Data Model Source:</strong> Cornell, L.P. and Klarer, D. M. (2008). Patterns of Dissolved Oxygen, Productivity and Respiration in Old Woman Creek Estuary, Erie County, Ohio during Low and High Water Conditions. Ohio J. Sci. 108(3):31-43. </p>
